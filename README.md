# Responsive Portfolio Website

A fully responsive, modern portfolio website built from scratch to showcase my projects in development, graphic design, and video editing.

## 📌 Project Features
- Fully responsive layout (Mobile First Methodology).
- Clear and semantic HTML structure.
- Custom CSS variables and modern JavaScript functions.
- Fully functional contact form integrated via EmailJS.
- Interactive elements including smooth section scrolling and an infinite-scroll testimonial slider.
- Compatible with all modern browsers and devices.
